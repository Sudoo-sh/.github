## Using the brand

- Use the files as they are: do not recolour, stretch, rotate or add effects to the mark.
- Use the dark variants on dark backgrounds rather than placing the light mark on a dark box.
- The name is written **Sudoo.sh**, with a capital S and a lowercase `.sh`.

"Sudoo.sh" and the mark identify the official project; see the panel's
[trademark policy](https://github.com/Sudoo-sh/sudoo.sh/blob/main/TRADEMARKS.md) before using them for a fork,
product or service.
