# Sudoo-sh/.github

The organization's shared files: `profile/README.md` is the page shown at github.com/Sudoo-sh, and CONTRIBUTING.md,
SECURITY.md, the pull request template and the issue forms apply to every repository that has none of its own.

`scripts/setup-github.sh` creates and configures every repository of the organization and pushes the local folders;
ORG_SETTINGS.md lists the settings that only the website can change.

`brand/` holds the canonical brand files that every Sudoo.sh property copies: `mark.svg` (the mark for light
backgrounds), `mark-dark.svg` (for dark backgrounds), `mark-animated.svg` (the text cursor blinks, still under reduced
motion; for READMEs and hero art only), `mark-512.png`, the wordmarks `logo-light.svg` and `logo-dark.svg`, and the
1280 x 640 `social-preview.svg` with `social-preview.png` rendered from it (upload that one as a repository's social
preview).
